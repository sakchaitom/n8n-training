# การอบรมเชิงปฏิบัติการ (Workshop)
## "การใช้งานระบบเวิร์กโฟลว์อัตโนมัติ n8n และการประยุกต์ใช้ AI Agent เพื่อสนับสนุนการจัดการข้อมูลวิจัย"

**วันที่:** 24 พฤศจิกายน 2568
**เวลา:** 09.00 - 16.00 น.
**สถานที่:** ห้องอบรมคอมพิวเตอร์ อาคาร วช. 3 ชั้น 2

---

## หลักการและเหตุผล

สำนักงานการวิจัยแห่งชาติ (วช.) ในฐานะหน่วยงานให้ทุนวิจัยและนวัตกรรมของประเทศ มีหน้าที่จัดทำฐานข้อมูลและดัชนีด้านวิทยาศาสตร์ วิจัยและนวัตกรรมของประเทศ ได้มีการพัฒนาระบบข้อมูลสารสนเทศวิจัยและนวัตกรรมแห่งชาติ (National Research and Innovation Information System : NRIIS) และพัฒนาระบบคลังข้อมูลงานวิจัยไทย (Thai National Research Repository : TNRR)

กองระบบและบริหารข้อมูลเชิงยุทธศาสตร์ด้านวิทยาศาสตร์ วิจัยและนวัตกรรม (กบข.) จึงเห็นควรจัดอบรมเชิงปฏิบัติการเพื่อให้เจ้าหน้าที่ วช. มีความรู้ความเข้าใจในการใช้งานระบบ n8n สำหรับการสร้างกระบวนการทำงานอัตโนมัติ (Workflow Automation) และเครื่องมือ AI Agent ในการประมวลผล วิเคราะห์ และจัดหมวดหมู่ข้อมูลที่เกี่ยวข้องกับงานวิจัย

---

## วัตถุประสงค์

1. เพื่อให้เจ้าหน้าที่ วช. มีความรู้ความเข้าใจเกี่ยวกับการใช้งานระบบ n8n สำหรับการสร้างกระบวนการทำงานอัตโนมัติ (Workflow Automation)
2. เพื่อพัฒนาทักษะการใช้งานเครื่องมือ AI Agent ในการประมวลผล วิเคราะห์ และจัดหมวดหมู่ข้อมูลที่เกี่ยวข้องกับงานวิจัย
3. เพื่อเสริมสร้างความสามารถในการประยุกต์ใช้ระบบอัตโนมัติและ AI ในการลดขั้นตอนการดำเนินงานและเพิ่มประสิทธิภาพการปฏิบัติงาน

---

## กลุ่มเป้าหมาย

เจ้าหน้าที่ วช. ประมาณ 40 คน

## หัวข้อการอบรม

1. **พื้นฐานระบบ n8n** - แนวคิดและการสร้าง Workflow Automation ในรูปแบบต่างๆ
2. **Workshop 1 (พื้นฐาน)** - การสร้าง Workflow อัตโนมัติแบบง่าย
3. **การประยุกต์ใช้ AI Agent ในระบบ n8n**
4. **การสมัครใช้บริการ AI Provider และการสร้าง API Key**
5. **Workshop 2 (พื้นฐาน)** - การจัดหมวดหมู่/สรุปข้อมูลวิจัยด้วย AI Agent
6. **Workshop 3 (ขั้นสูง)** - การใช้ AI Agent ร่วมกับเอกสารและระบบอัตโนมัติ
